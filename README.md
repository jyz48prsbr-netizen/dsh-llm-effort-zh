# dsh-llm-effort-zh

把 DeepSeek Harness 模型选择器里的推理等级（reasoning effort）名称显示为中文，中文界面下更易读。

- 显示为：关闭 / 极简 / 低 / 中 / 高 / 极高 / 最大
- 中文界面把 `Provider default` 一行显示为「默认」
- **只改显示名称**：推理等级 id 与请求里的 `reasoning_effort` 参数值完全不变，不影响实际模型行为
- 装在 profile 中，升级 Harness 应用后仍然有效

## 原理

浏览器端按每个推理等级的 `id` 重新映射名称，而不是信任传入的显示文本——这样即使适配器改名或新增等级，未收录的 id 也会保留原名称。Host 端同时为中文消费者提供中文名称。

## 安装

在 DSH 的插件页通过本地目录安装，或用市场索引安装本包。安装后无需重启（Client 端即时生效）。

## 兼容

需要 dsh 0.2.x（Web Client 插件机制）。仅改变界面文字。
